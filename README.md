# Jarvis Voice Assistant
A Python-based voice-controlled assistant that can perform various system tasks using voice commands. It is designed to simplify daily activities by enabling hands-free interaction with the computer.

## Features
- Voice recognition and command processing  
- Open websites and perform Google searches  
- Open applications and system tools  
- Text-to-speech response system  
- Provides date and time  
- Executes basic commands and queries
- 
## Tech Stack
- Language: Python  
- Libraries:
  - SpeechRecognition  
  - pyttsx3  
  - datetime  
  - webbrowser  
  - os
